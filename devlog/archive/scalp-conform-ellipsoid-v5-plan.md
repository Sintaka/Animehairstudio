## 0. 一句话结论

第四版的病根是**一个 `min`**：`axisPoint = (C.x, Math.min(C.y, P.y), C.z)`。
`P.y < C.y` 时 `min` 取 `P.y` ⇒ 径向纯水平 ⇒ **本来就已经是正确的纬线包裹**（这正是发尖手感对的原因）；
`P.y > C.y` 时 `min` 取 `C.y` ⇒ 轴退化成**头心一个点** ⇒ 弯曲变成「过头顶的大圆包裹」、轴倾斜 ⇒
用户看到的「根部弯进头皮、不往后弯」。用户描述的「纬线的中心偏移球心而往北极去、且保持在一个横切面中」
就是把这个 `min` 去掉：`axisPoint.y = P.y`（恒竖直轴 + 恒水平径向），再把半径改成从**椭球**推出。

**已拍板方案：L1 纯纬线，不做任何极区软化。** 用户原话：
> 「改成纯纬线 L1, 这几版的效果不行, 还是过于偏向切线偏折」
> 「椭球只是近似模型, 暴露数据给用户简单调一下近似即可」

即：`Reff` 就取纬线半径本身，**不向三维半径混合**（L2/L3/L4 全部作废，理由见 §4）。发根包裹角 241° 是
**接受的结果**，不是待修问题 —— 延续第四版 D8「就要包这么宽」的口径。椭球是**近似**，精度靠用户手调，
不追求贴合真实头皮网格（§6 D4）。

## 2. 根因

- **根因 A（本轮要修的）**：`min(C.y, P.y)` 在 `P.y > C.y` 时把弯曲轴从「竖直线」塌成「头心一点」。
  纬线圆心本应随高度上移并**留在水平横截面内**（用户原话：「纬线的中心也是偏移球中心而往北极去而保持在一个横切面中」），
  `min` 把这个偏移**钳到 0**，于是径向从水平变成三维斜向、轴跟着倾。
- **根因 B（本轮顺带修）**：`radius / scaleX / scaleY / scaleZ` **一个都没被读**（只读 x/y/z）。
  放大头模不会让面板让开。第四版把这条记为 D7 的已知限制，本轮按用户要求重开。
- **非根因（勿夹带）**：弯曲内核 `panelBendCrossSection` 是**平面无关**的，只吃 2D 截面与曲率 k。
  换轴**不需要改内核**，这正是当年把它写成平面无关的理由。本轮**不动 curve-math.js**。

## 3. 数学模型：椭球的纬线截面

半轴 `(ax, ay, az) = radius × (scaleX, scaleY, scaleZ)`，中心 `C`。对某一行的点 `P`：

1. **归一化高度** `h = (P.y − C.y) / ay`，钳到 `[−1, 1]`；`c = sqrt(1 − h²)`。
2. **纬线截面**：过 `P` 的水平面 `y = P.y` 截椭球，得到一个**椭圆**（不是圆），
   中心 `O = (C.x, P.y, C.z)`、半轴 `A = ax·c`（沿 X）、`B = az·c`（沿 Z）。
   ⇒ **圆心随纬度升高朝北极偏移，且恒在水平横切面内** —— 这就是用户要的那条性质，`min` 抹掉的正是它。
3. **密切圆心**（各向异性的正确处理）：取 `P` 的方位角 `t`，椭圆在该处的曲率半径
   `ρ = (A²sin²t + B²cos²t)^{3/2} / (A·B)`，内法向 `n̂ₑ`，密切圆心 `O_osc = P_e + ρ·n̂ₑ`。
   **球退化自检**：`ax=az` ⇒ `A=B=ρ` 且 `n̂ₑ` 指向 `O` ⇒ `O_osc = O`。所以**球的情况与「纯纬线」逐位相同**，
   默认头模（scale 全 1）下这一步引入零风险。
4. **弯曲轴** = 过 `O_osc` 的**竖直**线。`r̂ = normalize(P − O_osc)`（水平），`Rh = |P − O_osc|`。
5. **极区软化**（见 §5，解决 `Rh → 0` 时 k 发散）：`Reff = lerp(Rh, R3, w)`，`w = max(0, h)²`，`R3 = |P − C|`。
6. `k = amount / (Reff + gap)`，弯曲平面 `(x̂_t, r̂)`，`x̂_t = normalize(frame.x − (frame.x·r̂)r̂)`，
   `â = x̂_t × r̂`。**内核不变**，仍走 `panelBendCrossSection`。

### 极点处的量级（**用户已接受，不软化**；仅极点钳位防 NaN，见 §5）

`Rh` 是**纬线半径**，趋近北极时 → 0，于是 `k = amount/(Reff+gap) → amount/gap`。实测（球面纬线扫描，amount=0.87、gap=0.02）：

| 距头顶张角 θ | y | Rh | k | 包裹角 `k·halfWidth` |
|---|---|---|---|---|
| 90° | 0.900 | 1.000 | 0.853 | 122° |
| 60° | 1.400 | 0.866 | 0.982 | 141° |
| 30° | 1.766 | 0.500 | 1.673 | **240°** |
| 10° | 1.885 | 0.174 | 4.493 | **644°** |
| 1° | 1.900 | 0.017 | 23.2 | **3327°** |

第四版的 `min` 是**偶然**避开了这个奇点（它把高纬度全按三维半径算）。去掉 `min` 就必须显式处理，
否则「发根在头顶附近」这一**最常见**的刘海构型会直接卷成一团。

**注意概念区分**：纬线圆的曲率 `1/Rh` 含**测地曲率**分量，不等于曲面法曲率。球面的法曲率恒为 `1/radius`
（Meusnier 定理，探针已自检：7 个点全部收敛到 1.0，误差 <1e-5）。两者在赤道相等、越靠极点分歧越大。
「该用哪个」是**设计取舍不是对错**，见 D2。

**L2/L3/L4 全部作废。** 用户驳回理由（原话）：「这几版的效果不行, 还是**过于偏向切线偏折**」。
向 `R3`（三维半径）混合，等于让高纬度行按"斜向径向"的量级弯 —— 那正是第四版病根的**同一个味道**，
只是幅度小一些。用户要的是彻底切到纬线口径。补充的技术性理由：
- L2 在发尖把 `Reff` 从 `Rh=1.156` 硬改成 `radius=1.0`（发尖悬在头外，水平距离本就大于头半径）⇒ 动了发尖。
- L3 的权重 `h²` 是**偶函数**，发尖 `h=−0.859` ⇒ `w=0.738`，被拉向 `R3=1.44` ⇒ 也动了发尖。
- L4 虽然用 `max(0,h)²` 保住了发尖，但发根仍被拉到 `R3` ⇒ 仍是"偏向切线"的那一类。

## 5. 已拍板方案：**L1 纯纬线（椭球密切圆心，无软化）**

```
h    = clamp((P.y − C.y) / ay, −H, +H)      // H < 1，见下方「极点钳位」
c    = sqrt(1 − h²)
纬线椭圆：中心 O = (C.x, P.y, C.z)，半轴 A = ax·c（沿X）、B = az·c（沿Z）
密切圆心 O_osc = 椭圆在 P 方位处的密切圆心（球退化时 O_osc ≡ O）
r̂    = normalize(P − O_osc)   // 恒水平
Reff = |P − O_osc|
k    = amount / (Reff + gap)
弯曲平面 (x̂_t, r̂)，â = x̂_t × r̂   // 恒竖直；内核不变
```

性质（**构造性的**）：

| 性质 | 依据 / 实测 |
|---|---|
| **`scale=(1,1,1)` 且 `P.y < C.y` 时逐位等于现状 A0** | 球退化 ⇒ `O_osc ≡ O` ⇒ `Reff = Rh`；A0 在 `P.y<C.y` 时 `min` 取 `P.y` ⇒ 也是 `Rh`。**代数同式**。探针实测 `maxDiff = 6.939e-18`、逐分量全 true。 |
| 轴恒竖直、`Δy ≡ 0` | 径向恒水平 ⇒ `â` 恒竖直 ⇒ 点只在水平面内动 ⇒ 边缘**往后扫**。探针 4 组构型 × 7 点全部 `â=(0,−1,0)`、`Δy=0`。 |
| 发根包裹角 241.31°（球） | `Reff = 0.4164`。**接受**，见 §0。 |
| `scale≠(1,1,1)` 时**不再**逐位相同 | 有意如此，正是根因 B 的修复。探针实测 E3 下发尖 diff 0.11~0.37。 |
| 球退化自检 | `O_osc→O`、`Reff→Rh`，探针 `maxErr = 1.11e-16`。 |

### 极点钳位（**这不是软化，是防 NaN**）

`h` 必须钳到 `|h| ≤ H`（`H = 1 − ε`，建议 `ε = 1e-3`）。理由是实测出来的一个**真实缺陷**：
`h = ±1` ⇒ `c = 0` ⇒ `A = B = 0` ⇒ 密切圆半径 `rho = (0)^{3/2}/(0·0)` = **0/0 = NaN**。
而 `panelBendCrossSection` 第一行是 `const k = Number(curvature) || 0`，**NaN 是 falsy ⇒ 静默变 0**
⇒ 该行**完全摊平成直线**，无报错。既有守卫 `Reff < 1e-6` 抓不到（`NaN < 1e-6` 为 false）。

**这不是理论边缘情形**：`scaleY=0.9` ⇒ 椭球顶 `y = C.y + ay = 1.8`，而真实档发根 `y = 1.8326` > 1.8
⇒ 用户当前测试档 + 用户点名的 E3 构型就会触发，表现为发根从"包裹"瞬间跳到"完全摊平"。

两道措施都要上（**互补，不是二选一**）：
1. `h` 钳位到 `|h| ≤ 1 − 1e-3` ⇒ `c ≥ 0.0447`、`A/B > 0` ⇒ **NaN 不再产生**（治本）。
2. 守卫从 `Reff < 1e-6` 扩成 `!Number.isFinite(Reff) || Reff < 1e-6` ⇒ 让守卫名副其实（兜底）。

钳位的**代价必须说清**：行高过椭球顶时按最高纬线处理 ⇒ `Reff` 有下界 ≈ `0.0447·min(ax,az)`，
`k` 因此有上界 ≈ `amount/(0.0447·min(ax,az) + gap)`。这**不改变 §0 的"不软化"决定** —— 它不向 `R3` 混合，
只是把纬线椭圆截在极点前一丝，避免 0/0。

### D11 的三难（实测确认，**不是可以绕开的实现细节**）

下面三条**最多只能同时成立两条**：

1. **发尖逐位不变**（你的硬要求）
2. **头的尺寸/高度影响 conform**
3. **`amount=1` ⇒ 弧半径恰为 `Reff+gap` ⇒ 同心面、不穿透由构造保证**

成因：要 (1)+(3) 就必须取 `Reff = |P − 轴|`（到轴的距离）；而在**圆**上「圆心到点的距离」只由点自己的水平位置决定，
半径与高度代数上被消掉 —— 这正是 (2) 失效的机理。若改取 `Reff = ρ`（纬线自身的曲率半径）则 (2) 成立、
但发尖 `Reff` 从 1.156 掉到 0.512 ⇒ 包裹角 99° → **203°**，(1) 直接破。

**已选 (1)+(3)，放弃 (2)。** 代价与补偿：
- 「包松/包紧」由**现有的逐 lock `gap`** 提供（`k = amount/(Reff+gap)`），这个旋钮已经存在且更合适（逐片可调）。
- 「竖轴位置」由**现有的 `scalpSurface.x/z`** 提供（实测有效）。
- 新增的 2 个滑杆只负责**各向异性**（X:Z 比值），这是现有旋钮覆盖不到的唯一自由度。
- **相对第四版的回退**：第四版有一条测试断言「移动头心必须改变弯曲」（`⑦` 与「头心跟随」两个用例）。
  球构型下这条现在**必然失败**，且这是模型的数学必然、不是 bug。Phase 3 要把它重写成正确的不变式：
  「移动 `C.x`/`C.z` 必须改变弯曲」+「`C.y` 仅在 `ax ≠ az` 时改变弯曲」。**不许简单删掉这两条。**

### D9 落地：参数集定义

新增一组**拟合椭球**参数，与 `scalpSurface` 平行但独立：

**最终参数集（2 个，D11 裁决后从 4 个收窄）**：

| 参数 | 默认 | 区间 | 语义 |
|---|---|---|---|
| `fitScaleX` | 1 | 0.5 – 1.5 | X 半轴（Width） |
| `fitScaleZ` | 1 | 0.5 – 1.5 | Z 半轴（Depth） |

⇒ 半轴 `(ax, ay, az) = (fitScaleX, 1, fitScaleZ)`，中心复用 `scalpSurface.x/y/z`。
`ay` 与整体半径**写死为 1**（= 默认头模的尺寸，头在 `y ∈ [C.y−1, C.y+1]`）。
默认全 1 ⇒ 与球构型等价，"没动过新滑杆"的工程行为不变。

**为什么只有 2 个**：见 D11。简言之，球构型（`ax == az`）下纬线截面是**圆**，而圆的密切圆心就是圆心本身
⇒ `Reff = hypot(P.x−C.x, P.z−C.z)`，与半径、`ay`、`C.y` **数学上完全无关**（实测 `maxDiff` 精确为 0，
不是很小而是恰好 0）。所以 `fitRadius` 与 `fitScaleY` 在默认球构型下是**死控件**，不能上。
**注意**：它们在 `ax ≠ az` 时会变有效（实测 7.68e-3 / 8.12e-3），把它们写死为 1 因此是一个**明确的取值选择**，
不是"反正没影响"。同理 `C.y` 在各向异性下仍然有效。

**默认值的唯一定义点仍是 `curve-math.js` 的 `PANEL_SCALP_CONFORM_DEFAULTS`**（现有约定，`index.html` 的
`value=` 与 app.js 的创建默认必须同值 —— 这类三处漂移在本仓库有先例）。

### D10：建议做成**全局**（一份，不随 lock 走）

椭球描述的是**头**，而头只有一个 —— 每片头发各有一个头形在概念上就是错的。建议照 `scalpSurface` 的样子
放一份全局对象（存档里与 `scalpSurface` 并列），**不进 lock**。

由此省掉的接线：逐 lock 的 7 类路径、镜像拷贝、逐 lock 撤销捕获、按下标重映射 —— 全都不需要。
现有 `panelScalpConformAmount/Gap` 仍**保持逐 lock**（那两个是"这片头发贴多紧"，确实该逐片调）。

**"某片头发想贴到更外面的一层"这个需求已经由逐 lock 的 `gap` 覆盖**，不需要靠逐 lock 椭球实现。
若你确实要逐 lock 椭球（例如同一工程里两种发型层用不同头形），说一声，Phase 1 的写集要相应扩大。

## 9. 已知未解项（本轮**不**处理，避免夹带）

1. **UV 的 U 尺度漂移**：`uv-unfold` 的 U 由 row 0 逐段**弦长**累加，弯后弦长和 ≠ 原弧长（实测 0.9925~1.046）。
   解法已知（给 `gridUvTable` 传未弯曲的 `referenceCircumference`，参数已在签名里）。第四版已裁决"等形状定下来"。
2. **头皮 FFD lattice 与 `scalpArtistShape` 不参与**（D4）。解析椭球是近似；用户拖过 lattice 后误差无上界。
3. **`camber ≠ 0` 时"不穿透"会破**：积分器从 `sample(0)` 起步，`b0 = curvature·halfWidth ≠ 0` 把卷绕圆心推离轴 `b0`。
   `amount=1.0` 真实链穿透 +0.249。第四版 D11 用户已知情接受（「仍然留着, 我不会拉到 1.0」）。**本轮不改**。
4. **`α = 90°`（宽度轴与径向平行）零测集**：守卫 `lengthSq < 1e-12` 返回 null ⇒ 位移从 ~1.75 跳到 0。浮点上基本不可达。
5. **panel 没接 sweep 自交缓解**：`sweepCurvatureResponse` / `smoothSweepChains` / `smoothSweepFrames` 在
   `panel-tip-strand.js` 一次都没被引用（普通发丝/split/hair card 都接了）。既有缺口，与换轴正交，建议单独一轮。
6. **`scripts/verify-scalp-conform.mjs` 默认档写死** `D:/Downloads/Sussurro_v1_0060.ahs`，环境相关，未确认是否存在。
7. **非球构型下「不穿透」不再由构造保证**（本轮椭球探针新发现，**勿沿用第四版的无条件说法**）。
   第四版的论证前提是"头在轴周围的横截面是圆、半径 ≤ Reff"；椭球的横截面是**椭圆**，其它方位角的
   水平半径可以**大于** `Reff`，于是沿密切圆卷绕的边缘会切进头里。实测边缘椭球归一化深度：
   `scale=(1,0.9,1.6)` 下 P4 **−0.605**、P5 **−0.668**；`scale=(1.4,0.9,1.6)` 下 P5 **−0.393**（负 = 钻进去）。
   球构型（`scale=(1,1,1)`）**不受影响**，仍由构造保证。⇒ 这是"椭球只是近似"的代价之一，
   与 §9-2 同类：**记为已知限制**，靠用户手调椭球参数回避。若视口里不可接受，再单独一轮处理。
8. **椭球下包裹松紧随方位角明显不对称**（同上探针）：同一高度 `y=1.4`，`scale=(1.4,1,1)` 下正面（+Z）
   包裹角 69.33° 而侧面（+X）173.42° —— **2.5×**；`scale=(1.4,0.9,1.6)` 下反过来（正面 111.41° > 侧面 76.90°），
   方向随 `ax/az` 相对大小翻转。这是纬线模型在椭球上的**固有几何行为，不是 bug**，但用户只调一个轴时
   会感到"正面和侧面松紧不一致"，需在 UI 说明里提一句。
